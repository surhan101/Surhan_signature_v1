External Signature Gateway

Secure API gateway for external systems to request internal Ac Footer signatures without exposing employee signature files.

API Key HMAC SHA256 Ac Footer Sequential Workflow Webhook Callback Signed PDF

Create Request Endpoint

POST /api/method/surhan_signature.api.external_signature_gateway_create_request

Headers:

X-Surhan-Api-Key: sgw_xxxxx
X-Surhan-Timestamp: 1760000000
X-Surhan-Signature: sha256=<hmac_sha256(timestamp + "." + raw_body)>

Status Endpoint

POST /api/method/surhan_signature.api.external_signature_gateway_status

Use the same API key and HMAC signature headers.

Create Request Payload

{
  "external_system": "demo-external-system",
  "external_reference": "EXT-REQ-1001",
  "reference_doctype": "Internal Signature Demo Document",
  "reference_name": "ISD-2026-00003",
  "replace_ac_footer": 1,
  "callback_url": "https://external-system.example/callback",
  "signers": [
    {
      "employee": "HR-EMP-00001",
      "order": 1,
      "action": "Both",
      "can_reject": 1
    }
  ],
  "metadata_json": {
    "source": "External HR System"
  }
}

Security Rule

The external system never receives the raw stored employee signature. It receives request status, verification URL, signed PDF SHA256, and PDF link only when authenticated and authorized.
